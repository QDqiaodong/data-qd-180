# 接收站保护圈协调 v1

使用者是临时活动频率协调员，输入的是已排定发射计划，不分配频率。stations含唯一id、有限十进制度lat/lon、正整数protection_radius_m。transmissions含唯一id、station_id发射端、receiver_id接收端（两端不同且存在）、整数center_hz/bandwidth_hz和带时区start/end。频段不得跨过0Hz。单次≤500站/300次发射，每次正时长≤7日。

对每个有向受害接收任务v和其他发射s，要求同时满足：
1. 半开时间区间有正长度交集；统一UTC，接触端点不算重叠。
2. 占用频段[center-bandwidth/2,center+bandwidth/2)有正宽度交集；用双倍整数Hz计算后输出Fraction字符串，支持半Hz边界。
3. s发射站至v接收站的大圆距离≤接收站声明保护半径，地球半径6371008.8m。阈值使用未舍入距离；报告距离保留3位小数。

仅排除与自身相同的任务，不排除同址其他发射任务。方向不能合并成无向对：A干扰B，不表示B干扰A。每行列出双方任务、受害接收站、干扰发射站和时间/频率交集证据。clear_transmission_ids表示该任务的接收端未被发现冲突，不能保证其发射不干扰其他站。

这是一种由用户声明保护半径的几何筛查模型；没有地形、功率、天线、接收选择性或真实传播预算，不声明无线电许可/真实频谱安全。后续可从相同站点、频道和接收关系接入更具体的物理或排程规则。CLI先完成核验再原子新建报告，错误退出2并保留已有目标。

计划变更工作台（跨进程本地台账、提案与接收方确认）另行定义于[工作台契约](workbench.md)，其冲突计算复用本文模型，不改变 `radio-coordinate` 行为。

活动结束后的现场设备日志复核（重启纪元、带误差范围的联合校时、实测频道、有向冲突确定性与分组联合极值）定义于[执行观测复核契约](observations.md)，通过可选的 `radio-coordinate --observations` 进入；不传该参数时本文件描述的原报告与失败语义完全不变。

活动期间的接收保护日报重算与更正（两个发布视图、台站资料版本与优先级、缺失/争议的未决结论、逐任务接收时间线与更正清单）定义于[重算与更正契约](protection.md)，通过独立的 `radio-protection` 命令进入；不改变本节与上述其它命令的语义。
