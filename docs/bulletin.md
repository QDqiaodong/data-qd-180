# 可公开接收统计公告 `radio-bulletin` v1

活动主办方分批公开各场馆在频道组上的接收统计，用于下一届估算值守人力。接收明细计划本身不能外发：部分场馆在某频段的接收需求保密。即使本次不直接发布明细，把新的汇总与历史公告联立也可能反推出受保护格。本命令在**同一版冻结计划**上，按明确的公众所知模型逐请求审查每个统计口径，产出可公开的统计公告，并留下下次审查可直接作为 `prior` 复用的累计公开口径与精确值。

只用 Python 标准库；离线运行；判定全程整数运算，**不逐微秒、不逐个可能汇总值、不逐张可行矩阵枚举**。原 `radio-coordinate`（含 `--observations`）、`spectrum.service.run`、`radio-workbench`、`radio-arrange`、`radio-protection`、`radio-settle` 的用法与契约均不变。

## 入口与退出约定

```sh
radio-bulletin --source PLAN.json --rules RULES.json --output BULLETIN.json
```

未安装时可在源码树运行 `PYTHONPATH=src python3 -m spectrum.bulletin_cli ...`。

- 成功（包括有请求被扣留）：退出 0，stdout 只打印公告 `summary`（计数，不含任何格值），公告经临时文件**原子新建**于 `--output`；目标已存在则拒绝（退出 2）并保留原目标，绝不覆盖。
- 任一输入契约错误、历史与冻结计划不符、或历史本身已破坏保护差距：退出 2，stderr 一行 `radio-bulletin: <原因>`，不发布公告。
- 两份输入各自沿用 **8 MB** 上限，重复 JSON 键、非有限常量、布尔值冒充整数一律拒绝。
- 扣留是正常业务结果，不新增任何公开事实，也不输出扣留值、私有明细或摘要指纹。

公开纯函数 `spectrum.bulletin.build_bulletin(plan, rules)` 不读写文件，可独立测试；契约违例抛 `ValueError`。`spectrum.bulletin.PublicRegion` / `Circulation` 暴露公众可行域与下界环流引擎，供独立核对。

## 计量（PLAN 复用原校验与时间语义）

PLAN 沿用原 `stations`、`transmissions` 结构与限制，台站身份、发射/接收站引用、正整数中心频率与带宽、带显式偏移的半开时间语义与原契约一致，并被本命令**严格重新校验（含不参与统计的记录）**。

- RULES 的 `window` 是带显式偏移、正长度、最长七天的半开统计窗口（UTC 微秒整数）。
- 每项与窗口有**正长度交集**的发射，按其**接收站**映射到的场馆（行）与其**中心频率**落入的频道组（列，正整数 Hz 半开区间，各组互不重叠）归入唯一单元格。
- 计量值是该发射与窗口交集的**整数微秒数**。同一格内不同任务分别累加；任务重叠不去重；**不按带宽倍乘、不按发射站归属、不从冲突行推导**。接收站缺映射或中心频率不落入任何组即拒绝整份输入。无任务的格为零。

## 口径、公开区间与上界

可请求口径只有四种，均以原始 ID 唯一识别；全表合计没有附加 ID：

| scope | 附加字段 | 含义 |
| --- | --- | --- |
| `cell` | `venue_id`、`group_id` | 单个单元格 |
| `row` | `venue_id` | 一整行（场馆）合计 |
| `column` | `group_id` | 一整列（频道组）合计 |
| `total` | 无 | 全表合计 |

RULES 可为任一口径给出一个公开整数闭区间 `[low, high]`，同一口径最多一条；所有格非负，未另限的口径使用 `[0, 181440000000000]`，全表合计也受此上界约束。任一公开区间必须包含该口径的真实统计值，否则退出 2。

## 公众所知模型与保护审查

RULES 列出 1..12 个**不同**受保护单元格，各带正整数 `gap_us`。对一个公开记录集合，公众能推断的明细是**同时满足全部公开区间与全部已公布精确值的非负整数矩阵**。对每个受保护格，必须存在两张这样的矩阵，使该格取值相差至少 `gap_us`；各格的两张见证可以不同。审查**只**使用这一明示模型，不补充私有计划的任务存在性、非零位置或原始记录。

- `prior` 含此前公告的 `edition_id`、`revision` 与 `publications`（口径+精确值，可为空）。同一版全程使用同一冻结计划、窗口、分组与公开规则；**不跨版本合并记录**。口径不得重复或悬空。
- 先用私有计划核验所有公开区间及历史精确值；历史与真实统计不一致即退出 2。
- 再检查历史本身是否给每个保护格留下规定差距；历史已经泄露时**必须报错**，不能删历史或当作全新发布。缺约束不代表格真实值为零，历史也不要求达到当前发布策略才作为已知事实。
- `requests` 最多 32 项，按明确处理顺序列出不同口径。每项基于此前真实公开的事实（旧公告加本批前面已准许的值）处理。已公开口径标记 `published`，不重复写入。

## 准入本身也是公开信息

若某口径只有在它的真实值恰好不泄露时才被准许，那么即使不公布值，准入决定本身也暴露了私有信息。因此准入在当前公开条件下检查：对该口径**每一种仍然可能的整数结果**，假设公开该结果后，每个受保护格是否依然保有规定差距。只要有一种可能结果不满足保护，就**拒绝整个口径**；真实计划算出的那个结果即使安全也不例外。拒绝不新增任何事实。通过后才取真实统计值写入累计公开记录，供下一请求使用；之后的准入可随已公开的值改变。

## 精确判定（不按值或矩阵枚举）

矩阵约束是非负整数上的行/列/合计求和与区间界：其约束矩阵是运输（二分 b-匹配）关联矩阵，**完全幺模**，故线性可行域的每个顶点都是整数，整数可行性可由**下界环流**精确判定——在每格、每行、每列与合计各一条边的图上做确定性 Dinic 最大流。任一口径的可行取值构成**一个整数闭区间**；其两个端点用“强制该口径等于某值再判可行”的**二分搜索**求得，流的运行次数为 O(log U)（U 为上界），与 U 的数值大小无关。由于可行取值区间连续，“每种可能值都安全”的准入测试只需检查区间**两个端点**，从而在原计划上限内完成精确判定，无需逐微秒、逐可能汇总值或逐张可行矩阵枚举。

## 报告结构

| 键 | 内容 |
| --- | --- |
| `schema_version` / `tool` / `model` / `mode` | `1` / `radio-bulletin` / `frozen_plan_reception_statistics` / `privacy_reviewed_bulletin` |
| `edition_id` / `revision` | 版本标识；`revision` 为 `prior.revision + 1` |
| `window` | 统计窗口的 UTC ISO-8601 起止 |
| `requests[]` | 按请求顺序，每项含 `caliber` 与 `status`（`published` / `granted` / `withheld`） |
| `publications[]` | 累计公开记录，按确定顺序，每项含 `caliber` 与精确整数 `value`；只含已公开或本次准许的值 |
| `prior` | 与本公告同版、版次为 `revision`、`publications` 即累计记录的对象，**可原样作为下次 RULES 的 `prior`** |
| `summary` | 场馆/频道组/请求计数、已公开/准许/扣留数与累计公开数；不含任何私有格值 |

只允许公告给出已经公开或准许公开的精确值；扣留值、私有计划明细与摘要指纹不会出现在报告或 stdout。

## 确定性

输出只取决于业务值：输入数组重排、同一时刻换一种等价偏移写法，公告逐字不变。窗口时间一律转 UTC ISO-8601；口径按原始 ID 引用，累计公开记录顺序确定。
